# Autokorjaamo Hakola – E1 and E2 website project

## Pages and files

- `index.html` – home page
- `about.html` – about the workshop
- `listing.html` – services page
- `contact.html` – service request page
- `style.css` – shared styling and responsive layout for all four pages
- `script.js` – browser-side validation for the request form
- `plan.md` – website proposal and customer requirements
- `moodboard.md` – E2 design reasoning, colours, fonts and references
- `fixes.md` – broken/fixed notes and checks
- `ai-log.md` – AI use log to review and update honestly as you work

## Open in Visual Studio Code

1. Download and extract this project folder, or clone the repository:
   `git clone https://github.com/ShahriarSahed/Assignment-1.git`
2. Open Visual Studio Code.
3. Choose **File → Open Folder** and select the project folder.
4. Open `index.html` in a browser. You can also use the Live Server extension if it is installed.

## Before submitting

- Open all four pages and check that `style.css` loads on each one.
- Test at 320 px, 360 px, 768 px and 1280 px. There should be no sideways scrolling at 320 px.
- Test light and dark mode using the operating system or browser DevTools.
- Press Tab through every page and check that the focus indicator is visible.
- Test the service request form with both valid and invalid values.
- Validate each HTML page at https://validator.w3.org/nu/.

## Important

The service request form only checks fields in the browser. It does not email or store customer requests. It needs to be connected to the workshop's email before it can be used for real bookings.

The customer brief does not contain the business's phone number, email address, street address, opening hours, logo or prices. Do not invent these details; ask the customer for them.
